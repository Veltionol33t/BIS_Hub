# BIS_Hub

Internal Company Admin Hub for Bringing Industry Solution and Bethesher.

## Vercel environment variables

Configure these in Vercel for Production:

- `NEXT_PUBLIC_SUPABASE_URL` — Supabase project URL
- `SUPABASE_SERVICE_ROLE_KEY` — Supabase server-side secret key
- `ADMIN_HUB_PASSWORD` — shared internal Admin Hub login password

Never commit secret values to GitHub.
